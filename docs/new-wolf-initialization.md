# 新規Wonderful Wolf Entity初期状態の確定契約

## 適用対象
- 通常スポーンしたWolfのWWW初回変換（同期・非同期）
- /www summon、任意Genome召喚、ウルフトラップで新規生成したWolf
- 両親Genomeから正常生成され、WWW個体として確定した繁殖直後の子Wolf

## 初期状態
- Genomeと出生時Phenotype Snapshot、Owner、世代、血統、モード、所持品等は生成済みIndividualを正として保存し、不必要に書き換えない。
- 初回登録の直後、実効能力10種を生成時年齢・性格・特性・怪我・管理上書き値から計算して、適用可能なPaper Attributeへ投影する。成体と子個体の双方へ初期投影する。
- 初期Attribute投影が成功した後、現在HPを投影済み最大HPに合わせて満タンに設定する。既存のWolfが持っていたHP絶対値を新しい最大HPへ持ち越さず、生成直後の意図せぬ撤退を防ぐ。
- 保存PDCとは別の一時的なRuntime/AI情報は初回生成時にWWW側で管理する。既存のowner/tame・baby・Wolf variantは尊重する。

## 非適用対象
- チャンクのアンロード/ロード、プラグイン再起動、既存WWW個体のPDC復元、能力の定期再投影、/www modify、config reload、通常の回復や被弾には全回復処理を適用しない。
- WGL繁殖失敗で通常Wolfとして残す子、通常Wolfに対する自然変換抽選落選個体は初期化対象外。

## 確認
- 各初回生成経路で属性反映と現在HP=最大HPを確認。
- 繁殖で生成した子を確実に初期化し、親や他個体のHPを変更しない。
- 再読込・定期更新で負傷状態を維持する。
- 生成時のHP初期化と戦闘・攻撃速度問題は別問題として評価する。
